## What is MindForge?

MindForge is a practice game made of eight quick tasks inspired by well-known research paradigms. Each game adapts to you: finish a session with 80% accuracy or better and you move up a level, drop under 50% and it eases off so it always feels fair. There is a Kids mode (ages 6 to 12) and a Teen and Adult mode, a daily streak, XP and ranks, and a skill radar that fills in as you improve.

| Game | Skill practised | Inspired by |
|---|---|---|
| Pattern Logic | Reasoning | Number-series and Raven-style puzzles |
| Spark Memory | Working memory | Corsi block-tapping task |
| Colour Clash | Attention | Stroop task |
| Echo Letters | Focus and updating | n-back task |
| Spin Shapes | Spatial skills | Mental rotation (Shepard and Metzler) |
| Logic Lab | Deduction | Linear syllogisms |
| Tower Plan | Planning | Tower of Hanoi |
| Odd One Out | Verbal logic | Classification tasks |

## How to play

1. Open the demo link and choose **Kids 6 to 12** or **Teen and Adult**.
2. Pick a game and press **Play**. Tap or click your answers (number keys 1 to 4 also work).
3. Tap **The science** on any card to read what the task is based on.

## Run it on your computer

No install needed. Download `index.html` and open it in any modern browser. It works offline.

## Privacy

Your progress is saved only in your own browser (local storage). There are no ads, no accounts and no tracking, and nothing is sent anywhere.

## Important note

MindForge is a cognitive-skills practice game inspired by established research tasks. It is designed for entertainment, practice and self-reflection. Scores are game-performance indicators, not IQ scores, diagnostic results or standardized psychological assessments. Skills may improve with practice, but transfer to broader abilities is still debated by researchers.
